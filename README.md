
# NETWORKWALKS-Djama-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP

## Week 1: Cybersecurity Lab Setup

### Project Overview
This project focuses on setting up a virtual cybersecurity and penetration-testing laboratory using VirtualBox and Kali Linux.

The purpose of this lab is to learn and practice cybersecurity concepts in a virtual environment over a four-week period.

### Week 1 Objectives
- Install Oracle VirtualBox.
- Configure VirtualBox network settings.
- Install Kali Linux.
- Configure Kali Linux network settings.
- Establish a working virtual cybersecurity laboratory.
